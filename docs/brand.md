# عمارة نعناعة — World & characters canon (all seasons)

## The world
عمارة قديمة في حتة شعبية في القاهرة، 7 أدوار من غير أسانسير (إفيه متكرر)، بير سلم، وبكرة قديمة بتطلّع الحاجات. كل موسم = سر جديد في العمارة.
| المكان | التفاصيل الثابتة |
|---|---|
| السطوح | خزان مية، غسيل، فتحة تهوية نازلة على السابع، مكان خطط العيال السرية |
| الدور السابع | شقة عم رشدي (كانت مقفولة 30 سنة) — راديو، ساعة بندول، مكان صورة على الحيطة، البكرة بره الشباك |
| الدور الخامس | أستاذ فهمي (الموسم 1) |
| الدور التالت | طنط سوسن |
| الدور التاني | الحاجة نعناعة + توتة + شطة (المطبخ، بلكونة الغسيل) |
| الأرضي | دكة البواب، صناديق البوستة، باب البدروم |
| البدروم | لوحة الكهربا العمومية — **سر الموسم التاني** |

## Series format (every season)
- ~10 daily episodes, each 1.5–2.5 min, horizontal 1920×1080 + vertical 1080×1920 version.
- Episode skeleton: hook (≤3 s, scariest moment or last episode's cliffhanger) → title card → answer to yesterday's puzzle (green «إجابة امبارح» box) → events → audience puzzle mid/late («لغز النهارده: ... اكتبوا في الكومنتات» + gold puzzle box) → cliffhanger → endcard «الحلقة X بكرة».
- Season compilation movie: hook montage → title → animated character intro → all episodes with titles/endcards/recaps/puzzles cut (`movie/`).
- Season trailer before each new season.
